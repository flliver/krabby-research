# Krabby Uno v0.3 hardware

`pcb/` contains the PCB definitions, pin maps, bring-up exports, and November 9 CAD project relocated from `hardware/PCB-v0.3/PCB/`. The existing November 5 CAD, schematic, BOM, fabrication, and assembly files remain here unchanged; these revisions have not been merged or replaced.

The hardware-tested STM32G474 firmware is at [firmware/stm/uno-v0.3](../../firmware/stm/uno-v0.3/README.md). Its [USB first-load instructions and combined HEX](../../firmware/stm/uno-v0.3/Instructions/FirstLoad.md) are kept together. Historical implementation records and recovery ZIP archives remain under `hardware/PCB-v0.3/`.
