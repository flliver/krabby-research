## 5. What passing each gate means (4b)

Thresholds v1.2; HALTs are prompts; the chance-HALT run sum (1.197) is reported, not capped.

- s1: a side-first walker formed (floors: survival >= 0.80, ratio >= 0.50, side22 not SLOW).
- c4 .. c6: widening the command set cost no translation (the same floors).
- c6x: the clock-free walker tracks and turns (floors; clock hidden from here on).
- p2a: head-of-record capability (survival >= 0.90 / ratio >= 0.70 floors, side22 FAST/FAST, field_hard pooled es1-4 >= its three-seed line).
- p3a: stable at 90 kg (the a-priori p3a.stable90 lines on suite + field_light) and no unloaded regression (the paired 0-kg check vs the run's own p2a: v1.2 track_err for the translate categories, a one-sided ratio drop for move_turn).
- p3b / p3c: measured ceilings (budget_bound at N_p 3000); a miss ends the stage, never the run.
- T*: the trained payload head with the highest max_stable that passes its paired 0-kg check.
- Student: the floors, plus paired completion >= T* - max(0.05, 2 SE_diff, split 0.0) on the WORLD rows (field_hard / field_light / ring_obst / field_turn on Student-Play). The body / grid / sweep reads in the report are post hoc. Camera use is UNVERIFIED (CHARTER 2026-10-17).
- SN: G1-G5 (G1 / G2 stillness WATCH since v1.1).
- SH: K1-K6, K4 <= 3/800 misses per env seed (D9); a lazy R_h control beside T* re-anchors a line it fails too (walker-caused, DESIGN 3.6).
